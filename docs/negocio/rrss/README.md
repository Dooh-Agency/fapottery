# RRSS — Panel de trabajo de FA Pottery

Punto de entrada para planificar, diseñar y publicar contenido de Instagram. Abrir este documento primero.

## Ahora: siguiente paso

**Próximo contenido del calendario:** `Materia, luz y manos` — lunes 10 de agosto.

- **Etapa:** TOFU (descubrimiento).
- **Formato:** foto limpia; sin texto sobre la imagen.
- **Objetivo:** abrir la secuencia con una imagen editorial y sensorial de la materia.
- **Canva AI:** crear una imagen base con el prompt de la guía de Canva; usar como estilo una referencia de Yonobi Studio.
- **Copy:** disponible en la sección correspondiente del documento de copys.

Después de crearla en Canva, guardar el diseño como borrador y volver aquí para preparar el reel `Así es tu primera clase`.

## Orden de trabajo

1. **Mirar la grilla** para entender el ritmo visual.
2. **Abrir el calendario** y elegir la próxima pieza.
3. **Usar el prompt** de Canva o preparar material real según corresponda.
4. **Copiar el copy** aprobado y adaptarlo sólo a la imagen final.
5. **Registrar** si se publicó, se pospuso o se sustituyó por otra pieza.

## Regla rápida antes de publicar

- ¿Es TOFU, MOFU o BOFU?
- ¿Lleva texto grande, texto breve o queda limpia?
- ¿La imagen generada se usa como atmósfera editorial o está representando un hecho real? Si es un hecho real, usar material real.
- ¿El copy corresponde al español de España informal?
- Si es BOFU: ¿la fecha, plazas, precio, stock, canal de consulta y capacidad están confirmados?
